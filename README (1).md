# Array Sum — сумма элементов массива, кратных K

🇷🇺 Русский · [🇬🇧 English](README.en.md)

Консольная программа на Python: вычисляет сумму всех элементов целочисленного массива, которые делятся без остатка на число `K`. Данные можно вводить и выводить через консоль и через файлы. Есть резервное копирование и восстановление входного массива.

## Описание программы

- Ввод массива: консоль (меню или аргументы) либо текстовый файл.
- Вывод результата: консоль и файл `output.txt`.
- Поддерживаются отрицательные числа, ноль и отрицательное `K`.
- Резервные копии входного файла с контрольной суммой SHA-256 (хранятся 10 последних).
- Только стандартная библиотека Python.

Пример: массив `4 7 12 15 20`, `K = 4` → подходящие элементы `4, 12, 20`, сумма `36`.

## Установка

**Требования:** Python 3.8+ и Git.

1. Проверьте Python:
   ```bash
   python --version
   ```
   На Linux/macOS может понадобиться `python3`.
2. Скачайте проект:
   ```bash

   cd calculator
   ```
   Либо нажмите **Code → Download ZIP** на странице репозитория и распакуйте архив.
3. Запустите:
   ```bash
   python main.py
   ```

## Руководство по использованию

### 1. Интерактивное меню
```bash
python main.py
```
| Пункт | Действие |
|---|---|
| 1 | Ввести массив в консоли и вычислить сумму |
| 2 | Загрузить массив из `input.txt` и вычислить сумму |
| 3 | Загрузить массив из другого файла и вычислить сумму |
| 4 | Сохранить текущий массив в `input.txt` |
| 5 | Создать резервную копию `input.txt` |
| 6 | Восстановить `input.txt` из резервной копии |
| 7 | Показать текущий массив |
| 0 | Выход |

### 2. Командная строка

| Команда | Что делает |
|---|---|
| `python main.py sum --array 4 7 12 15 20 --k 4` | Сумма для массива из аргументов |
| `python main.py sum --input input.txt --k 4` | Массив из файла, результат в `output.txt` |
| `python main.py sum --input input.txt --k 4 --output result.txt` | Результат в свой файл |
| `python main.py backup` | Создать резервную копию `input.txt` |
| `python main.py backups` | Список резервных копий |
| `python main.py restore` | Восстановить из последней копии |
| `python main.py restore <имя_файла>` | Восстановить из выбранной копии |

Пример:
```
$ python main.py sum --array 4 7 12 15 20 --k 4
Подходящие элементы: [4, 12, 20]
Сумма элементов, кратных 4: 36
```

### 3. Формат файлов
- `input.txt` — целые числа через пробелы или переводы строк: `4 7 12 15 20`.
- `output.txt` — исходный массив, `K`, подходящие элементы и сумма.
- `backups/*.json` — резервные копии (вручную не редактировать).

### 4. Ошибки
`K` не может быть нулём, массив не может быть пустым или содержать нецелые значения. При ошибке программа выводит сообщение `ОШИБКА: …`, а данные не изменяются.

### 5. Резервное копирование
Копия создаётся только из корректного `input.txt`. При восстановлении проверяется контрольная сумма; перед заменой `input.txt` текущая версия сохраняется как `*_pre-restore.json`. Хранятся 10 последних копий.
