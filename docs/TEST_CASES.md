# Тест-кейсы и результаты проверки

**Объект проверки:** Array Sum v1.0.0 (`main.py`) · **Основание:** `docs/TZ.md` · **Дата проверки:** 22.10.2026
**Среда:** Linux, Python 3.12. Все ручные тест-кейсы выполнены реальным запуском программы в чистой копии проекта.

Подготовка: чистая копия проекта (пустая `backups/`), запуск из корня проекта. Команды в таблицах записаны без префикса: `sum …` означает `python main.py sum …`. Если не сказано иное, `input.txt` содержит `4 7 12 15 20`.
Файлы `examples/array.txt` — `4 7 12 15 20`; `examples/negatives.txt` — `-12 0 8 5 -4`; `examples/multiline.txt` — массив `4 7 12 15 20`, записанный в три строки; `examples/invalid.txt` — `4 7 abc 15`.

## 4. Ограничения проверки
- Проверка выполнена на Linux с Python 3.12. Запуск на Windows и macOS (NFR-2) и на Python 3.8 вручную не выполнялся; программа использует только `pathlib`, `os.replace` и стандартную библиотеку, а на Python 3.8, 3.10 и 3.12 тесты прогоняет GitHub Actions.
- Время TC-36 (около 0,5 с) зависит от компьютера.
